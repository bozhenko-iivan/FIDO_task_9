# Task 9: Quotes REST API

**Technologies:** Node.js, Express

**How to run:**

Open a terminal in the root directory of the project.

Install the required dependencies:

`npm install express`

`npm install uuid`

Start the server:

`node task9/server.js`

The server will start on port 3000. The API is ready to accept POST, GET, PUT, and DELETE requests at http://localhost:3000/quotes
